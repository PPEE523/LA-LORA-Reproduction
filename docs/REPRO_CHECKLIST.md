## DP 机制

- [x] 逐样本 CPU 示例：用户确认 -20/+18 的梯度在 C=1 时分别裁剪为 -1/+1，均值 0；普通 batch 梯度为 -1。
- [x] 初步端到端：用户确认逐样本裁剪、Gaussian 噪声、滤波训练完成；现有单轮日志有最终准确率，不等同于严格 DP 验收。
- [ ] 裁剪上界：对多参数、含冻结/未参与参数、零梯度、极大梯度及不同 batch，逐个样本的拼接 L2 范数在裁剪后不超过固定 C（设定数值容差），并与独立手算/参考结果一致。
- [ ] 噪声缩放：无信号的重复采样结果满足预先定义的统计检验/置信区间；裁剪和噪声方差为 `(sigma*C)^2`、均值梯度方差为 `(sigma*C/b_actual)^2`，覆盖尾批、独立性及零噪声情况。
- [ ] 机制作用范围：明确 LoRA 活跃矩阵与分类头是否一同计入裁剪/噪声；所有正式基线的保护范围可比较；阈值和随机性无未经解释的数据依赖。
- [ ] 邻接与威胁模型：明确样本级/客户端级保护、add/remove 或 replace 邻接、服务器能见信息和可信假设；敏感度证明与实现归一化一致。
